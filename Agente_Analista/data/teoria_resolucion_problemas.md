# Naturaleza y tipos de problemas

## Objetivos de este capítulo

Al trabajar este capítulo se busca:

- **Mejorar las habilidades de pensamiento sistémico y creativo**:
  ver el problema como parte de un sistema de relaciones, no como un
  evento aislado; y abrir el espacio a soluciones no obvias.
- **Mejorar las habilidades para resolver problemas de forma
  disruptiva**: cuestionar las suposiciones heredadas ("siempre se ha
  hecho así") y considerar soluciones que cambian las reglas del juego,
  no solo las que optimizan lo existente.

Estos objetivos atraviesan todos los capítulos: cada herramienta se
aplica con doble mirada — la mejora continua (hacer mejor lo mismo) y
la disrupción (hacer algo distinto).

## ¿Qué es un problema?

Un problema es la brecha entre el estado actual y el estado deseado.
No es un síntoma ni una queja: es una diferencia medible entre "lo que
es" y "lo que debería ser". Si no hay brecha medible, no hay problema
que resolver; hay una preferencia o una percepción.

Tres elementos definen todo problema:

1. **Estado actual**: la situación observable y cuantificable de hoy.
2. **Estado deseado**: la meta, estándar o expectativa.
3. **Obstáculo**: lo que impide pasar del estado actual al deseado.

## Tipos de problemas

**Por su estructura:**

- **Problemas bien definidos**: estado actual, meta y método de solución
  son conocidos (ej. calcular el costo de un cambio de producción).
  Se resuelven con procedimientos establecidos.
- **Problemas mal definidos**: la meta o el método son ambiguos
  (ej. "mejorar la rentabilidad"). Requieren primero estructurar el
  problema antes de resolverlo.

**Por su origen:**

- **De ocurrencia**: algo que funcionaba dejó de funcionar
  (ej. caída de rendimiento en un lote). La solución busca restaurar
  el estado anterior.
- **De brecha**: nunca se ha alcanzado el nivel deseado (ej. llegar a
  un nuevo segmento de mercado). La solución requiere crear capacidad
  nueva.
- **De anticipación**: el problema aún no ocurre pero es previsible
  (ej. escasez de insumos en temporada alta). La solución es preventiva.

**Por su dominio:**

- **Técnicos**: máquinas, procesos, calidad. Causas verificables.
- **Humanos**: comunicación, motivación, errores de estimación.
  Causas mixtas; exigen datos y conversación.
- **De negocio**: precios, costos, mercado. Causas económicas
  cuantificables.

**Por el tipo de solución que exigen (mirada disruptiva):**

- **Problemas de optimización**: la respuesta es hacer mejor lo que ya
  se hace (más rápido, más barato, con menos errores). Mejora continua.
- **Problemas de rediseño**: la respuesta exige cambiar la estructura
  del proceso o del sistema (eliminar pasos, cambiar actores, nueva
  tecnología). Pensamiento sistémico.
- **Problemas de redefinición**: la respuesta cambia la pregunta misma
  (no "¿cómo vendo más flores?" sino "¿qué negocio debería ser este?").
  Disrupción.

Clasificar el problema en estos tres niveles evita aplicar soluciones
incrementales a problemas que exigen transformación, y viceversa.

## Errores frecuentes al reconocer problemas

1. **Confundir el síntoma con el problema**: "ventas bajas" es síntoma;
   el problema puede ser precio, calidad o canal equivocado.
2. **Formular el problema con la solución incluida**: "no tenemos un
   sistema nuevo" ya decide la solución. Mejor: "el registro de datos
   toma 3 horas diarias".
3. **Problemas sin dueño**: si nadie es responsable de cerrar la brecha,
   el problema se crónico.

## Preguntas de diagnóstico inicial

- ¿Qué está pasando que no debería pasar? (o qué no pasa que debería)
- ¿Desde cuándo? ¿Con qué frecuencia?
- ¿Cuánto cuesta o cuánto se pierde? (cuantificar la brecha)
- ¿A quién afecta y quién puede resolverlo?
- ¿Es de ocurrencia, de brecha o de anticipación?

## Regla práctica

Antes de buscar soluciones, escribe el problema en una sola frase que
incluya: brecha medible + contexto + costo. Si no puedes, el problema
aún no está reconocido: pasa al capítulo 2 (planteamiento).
